# Yavin Office Design — Office Space Design Website

⚠️ This template was originally created by Mohammed Sabry  
credit is required: github.com/Mohammedsabry13

A clean and professional corporate website for **Yavin Office Design**, a company specializing in transforming office spaces into inspiring and functional environments.

## 🛠️ Tech Stack
- **HTML5 & CSS3** — semantic two-page structure and custom styling
- **Bootstrap 5** — responsive grid, navbar, carousel, cards
- **Font Awesome** — icon set
- **Open Sans** — Google Fonts clean typography
- **Vanilla JavaScript** — counter animation, scroll-to-top, lightbox, Bootstrap init

## 📄 Pages
- `index.html` — Home (full one-page layout)
- `article.html` — Article detail inner page

## ✨ Features
- **Sticky navbar** — SVG logo + smooth scroll links (Details, Services, Projects, Contact) + outlined "Contact Us" CTA button
- **Hero header** — decorative star SVG elements, large headline with colored span, dual CTA buttons (More Details + Contact Us) and right-side image composition
- **Animated stats counter** — 4 counters (328 Happy Customers, 285 Issues Solved, 159 Good Reviews, 128 Case Studies) triggered via `data-target` attributes
- **Introduction section** — centered text with colored heading span on light background
- **Details section 1** — image + feature checklist with Font Awesome check icons
- **Details section 2** — reversed image + feature checklist layout
- **Services section** — service cards grid
- **Projects gallery** — project cards with lightbox/modal overlay on click
- **Testimonials carousel** — Bootstrap carousel with client review cards
- **Contact section** — form with name, email, message fields and submit button
- **3-column footer** — About text, links (Terms, Privacy, Menu), social icons (Facebook, Twitter, Instagram, Pinterest) + email
- **Scroll-to-top button** — fixed position with up-arrow image icon
- **Article detail page** — full article layout with large image, text sections, 3 advantage cards, gray info box, and same navbar/footer
- Fully responsive across all screen sizes
